# moviki-vault

Vault Obsidian do projeto **MOVIKI**, organizado pelo método **PARA**.
A raiz deste repositório **é** o vault — abra esta pasta como cofre no Obsidian.

## Estrutura

| Pasta | O que é |
| --- | --- |
| `00-Inbox/` | captura rápida, esvaziada semanalmente |
| `01-Projetos/` | esforço com fim e data |
| `02-Areas/` | responsabilidade contínua |
| `03-Recursos/` | referência que não exige ação |
| `04-Arquivo/` | concluído ou inativo |
| `_Templates/` | modelos de nota |
| `_Anexos/` | imagens e arquivos |

Comece por `000 Moviki — Home (MOC).md`.

## Para que este repositório existe

1. **Backup e histórico** do vault.
2. **Fonte GitHub na Base de Conhecimento do Project do Claude** — é assim que o Claude lê o vault em qualquer superfície (claude.ai, Cowork, celular), sem depender da máquina local.

Sync pelo plugin **Obsidian Git**. Instruções em `03-Recursos/R — Sync do vault (Obsidian Git).md`.

## Hierarquia de verdade

1. **Console do Firebase** — regras do Firestore e do Storage
2. **`claude/MAPA-MESTRE.md`** no Project — documento canônico
3. **Este vault** — derivado, navegação humana

Quando divergirem, o de cima manda.

## Aviso

Repositório **privado**. Não contém chaves nem segredos — e não deve passar a conter. Chaves vivem só na Vercel e nos Secrets do GitHub.
